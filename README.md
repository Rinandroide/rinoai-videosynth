## 🇬🇧 Overview

**RinoAI - VideoSynth** is a high-performance generative video synthesis engine designed for live VJing, audiovisual performances, interactive installations, and digital art creation.

Driven by a real-time biomorphic fluid engine, **VideoSynth** combines non-linear reaction-diffusion differential models with turbulent fractal vector fields, creating organic living visuals, refractive chromatic optical effects, and dynamic gravitational singularities.

---

### ✨ Key Features

* **🧬 Organic Reaction-Diffusion & Fluid Dynamics:** Real-time multi-layered fluid simulations with cellular morphogen evolution and chaos mutation parameters.
* **🌀 Interactive Gravitational Singularity:** Real-time mouse-driven vortex warping with an integrated **Autopilot LFO** mode for autonomous, fluid drift.
* **💎 Advanced Optical & Lighting Engine:** 
  * Physically inspired dynamic surface normals and Fresnel reflections.
  * Real-time soft raymarched shadows & ambient occlusion (AO).
  * Spectral chromatic dispersion and index-based optical refraction.
* **🔮 Built-in Symmetry & Kaleidoscopes:** Dynamic multi-axis symmetry generator for sacred geometry and hypnotic visual patterns.
* **🎛️ Dual-Language Cyberpunk HUD:** Integrated low-latency control interface available in **English** and **Italian**.
* **⚡ Ultra-Adaptive Performance Engine:** Configurable internal render scaling and dedicated High-Performance mode for high-FPS live stages.
* **🪟 Native Borderless Window:** Sleek custom frameless design with smooth title bar window dragging and seamless borderless fullscreen toggling.

## DEDICATED GPU OPTIMIZATION (NVIDIA RTX / RADEON RX)
If you are using a powerful graphics card (e.g., NVIDIA RTX or AMD Radeon series), go to the "6. PERFORMANCE AND RENDERING" section of the control panel, uncheck "High Performance Mode," and set the "Resolution Scale" to the maximum (1.0 / 100%) to unlock maximum fractal octave depth, ray-marched shadows, and full native-resolution Ambient Occlusion.

## 🚀 Download & Installation

Standalone setup packages are distributed via GitHub Releases. **No compilation or additional runtimes required.**

1. Go to the latest [**GitHub Releases**](../../releases) page.
2. Download the installer for your operating system:
   * **Windows:** `RinoAI-VideoSynth-Setup-x64.exe`
   * **macOS:** `RinoAI-VideoSynth-macOS-Universal.dmg` (for Intel & Apple Silicon)
3. Run the installer and launch **RinoAI - VideoSynth**.
